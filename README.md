# Normalized pCO2 Processing and Regionalization

This repository contains selected MATLAB scripts used for processing, visualization, and regional separation of normalized pCO2 datasets for the Mexican Pacific.

The workflows included here were developed using compiled and curated oceanographic datasets from multiple sources, including:
- research cruises,
- SOCAT-derived products,
- LDEO datasets,
- publicly available marine observations.

The examples demonstrate:
- data harmonization and preprocessing,
- regional data separation,
- temporal analyses,
- visualization workflows,
- figure generation in MATLAB.

The repository includes representative processing examples and selected workflows associated with the study dataset.

## Data source

The compiled database associated with this work is available at:
